QUESTION 1: STUDENT INFORMATION

============================================================

1. Object creation using new.
2. Default and parameterized constructors.
3. Constructor overloading.
4. Constructor chaining using this().
5. Copy constructors.
6. Static object counters.
7. Object references and reference assignment.
8. Passing objects as constructor arguments.
9. Arrays of objects.
10. Shallow copy and deep copy.
11. Association between objects.
12. Multiple objects sharing the same reference.


============================================================
STUDENT INSTRUCTIONS
============================================================

1. Write a complete Java program for every question.
2. Use separate classes wherever required.
3. Do not use Collections or Stream API.
4. Use constructors to initialize objects.
5. Test each program with multiple objects and different values.
6. Be prepared to explain object creation, constructor execution,
   and object-reference behavior.
7. Do not copy solutions. Understand the logic and implement it yourself.
