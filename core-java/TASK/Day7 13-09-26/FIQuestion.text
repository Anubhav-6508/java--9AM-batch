# Function<T, R> Functional Interface

Functional Interface → 
`Function<T, R>`
**Important:** No Stream API questions.

---

## Part A — Interview Questions

### 1. Basic Concept

What is the `Function<T, R>` functional interface in Java? What is the purpose of `T` and `R`?

### 2. Abstract Method

What is the abstract method of the `Function` interface? Explain:

```java
R apply(T t);
```

### 3. Input and Output

Why is `Function<T, R>` called a function when it accepts one input and produces one output?

### 4. Same Input and Return Type

Can the input type and return type of `Function` be the same? Explain with an example.

### 5. Different Input and Return Type

Can the input type and return type of `Function` be different? Explain with an example.

### 6. Multiple Arguments

Can a `Function` take two or more arguments? If not, which functional interface can be used for two arguments?

### 7. Lambda Expression

How can you implement `Function<T, R>` using a lambda expression?

### 8. Function as Method Argument

Can a `Function` be passed as a method argument? Explain why this is useful.

### 9. Function as Method Return Value

Can a method return a `Function<T, R>`? If yes, what would be the use of returning a function?

### 10. Comparison

What is the difference between:

* `Function<T, R>`
* `Consumer<T>`
* `Predicate<T>`
* `Supplier<T>`

Compare them based on their **input and output**.

### 11. Function Returning Function

Can a `Function` return another `Function`? Explain.

### 12. Custom Objects

Can `Function` be used with custom classes instead of `Integer` or `String`? Explain with an example.

### 13. Null Return

What happens if the `apply()` method returns `null`?

### 14. Own Functional Interface

Can we create our own functional interface similar to `Function`? Why would we do that?

### 15. Function vs UnaryOperator

What is the difference between `Function<T, R>` and `UnaryOperator<T>`?

### 16. Function vs BiFunction

What is the difference between `Function<T, R>` and `BiFunction<T, U, R>`?

# Part B — Coding Interview Questions

## 1. Convert String to Integer

Write a Java program using:

```java
Function<String, Integer>
```

to convert a numeric String into an Integer.

**Example:**

```text
Input: "100"
Output: 100
```


```java
Function<Double, Double>
```


```java
Function<Employee, String>
```

# Part C — Strong Interview Coding Question

## 11. Generic Function Processor

Create a generic method:

```java
static <T, R> R process(T value, Function<T, R> function)
```

The method should accept:

1. A value
2. A Function

and return the result produced by the Function.

### Test Case 1

```text
String → Integer
```

Example:

```text
"Java" → 4
```

### Test Case 2

```text
Integer → Integer
```

Example:

```text
5 → 25
```

### Test Case 3

```text
String → String
```

Example:

```text
"java" → "JAVA"
```

## Student Rule

**Do not use Stream API for these questions.**

The focus should be on:

```text
Functional Interface
        ↓
Function<T,R>
        ↓
Lambda Expression
        ↓
apply()
        ↓
Input → Processing → Output
```
